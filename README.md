# Газпромбанк.Тех — предрелизная подготовка страниц «Блог» и «Публикации»

Предрелизная подготовка страниц «Блог» и «Публикации» для сайта «Газпромбанк.Тех». Работа велась на основе готового проекта: были получены замечания тестировщика, тимлида и клиента, после чего все недочёты устранены, а статусы в баг-листе обновлены.

## Описание

Проект представляет собой две страницы — «Блог» и «Публикации». На этапе предрелизной подготовки был проведён полный цикл исправлений по баг-листу: от критичных ошибок вёрстки до оптимизации кода и подготовки к продакшену.

Все замечания были отработаны и закрыты. Итоговый баг-лист со статусами «Исправлено» доступен по ссылке:

[Баг-лист проекта (итоговый)](https://docs.google.com/spreadsheets/d/1auIn5vgK3tBPbCx6u-M3Z0kyBYy1AoM34aMH7232xpM/edit?usp=sharing)

## Стек

- HTML5 (семантическая разметка)
- SCSS / Sass
- БЭМ
- Flexbox / CSS Grid
- Live Sass Compiler (VS Code)

## Как запустить

1. Клонировать репозиторий:

```
git clone <url>
```

2. Открыть проект в редакторе кода.

3. Установить плагин Live Sass Compiler и настроить компиляцию в папку /css:

```json
"liveSassCompile.settings.formats": [
  {
    "format": "expanded",
    "extensionName": ".css",
    "savePath": "~/../css/"
  }
]
```

4. Запустить компиляцию Sass (Watch Sass).

5. Открыть нужную страницу в браузере.

## Что было исправлено

### Замечания тестировщика

- Проверки Lighthouse, связанные с вёрсткой, приведены в зелёную зону, явные ошибки устранены
- Десктопная версия article.html приведена в соответствие с макетом по Pixel Perfect
- Устранено наслаивание шапки на элементы страницы при скролле
- Исправлена неплавная смена состояния ссылки «категории» при убирании курсора
- Устранены ошибки в консоли
- Исправлено перекрытие текста изображением на разрешении <1100 px на главной странице
- Добавлены ховер и cursor pointer на ссылке
- Область клика у иконки бургера на планшетном и мобильном виде увеличена до 40 px
- Приведён в соответствие с макетом размер текста у кнопки
- Исправлено отображение картинки рупора в @2x на десктопном разрешении

### Замечания тимлида

- Добавлен метатег `<meta charset="UTF-8">` — устранены иероглифы вместо текста на главной
- Добавлен прелоад шрифтов через `<link rel="preload" ... as="font" crossorigin="anonymous">`
- Сгенерирован и подключён favicon (realfavicongenerator), иконки в папку favicon, site.manifest в корень проекта
- Фоновое изображение баннера подписки перенесено в разметку: выполнены кадрирование, ретинизация, оптимизация (Squoosh), добавлен webp-формат и ленивая загрузка
- Выполнена минификация CSS-кода
- Оптимизированы и минифицированы SVG-иконки в спрайте (SVGOMG)
- Проведена чистка кода: удалены комментарии, пустые и неиспользуемые селекторы
- Удалён неиспользуемый модификатор `--first` у карточки «Новости»
- Для transition использована переменная из variables.scss
- У transition явно указано анимируемое свойство (opacity)
- Убрано значение all у transition
- Удалены CSS !important и инлайн-стили в HTML
- Код отформатирован

## Критерии оценки, которым соответствует проект

### Вёрстка

- Резиновая вёрстка, корректное отображение на ширине от 360 до 4000 px
- Адаптация под все разрешения из макета
- Pixel Perfect (погрешность до 10 px)
- Сетки на Flex и Grid
- Подвал прижат к низу экрана при недостаточной высоте контента
- Утилитарный класс container для горизонтальной центровки
- Семантическая разметка: контент внутри main в тегах section
- Проверка на переполнение контентом

### Графика

- Растровые изображения подготовлены для экранов с плотностью 2x
- Изображения подключены с учётом адаптации
- Векторные изображения собраны в SVG-спрайт
- Форматы: JPG, PNG, SVG (+ webp для баннера)
- У спозиционированных графических элементов отключена кликабельность (pointer-events: none)

### Стилизация

- Препроцессор Sass
- Шрифты и цвета вынесены в SCSS-переменные
- Состояния элементов из UI-kit
- Визуальный отклик при фокусе с клавиатуры
- БЭМ-нейминг

### Формы и интерактив

- Поля формы внутри тега form
- Обязательные поля с атрибутом required
- У полей указаны name и id, у радиокнопок — value
- У кнопок заполнен атрибут type
- Явная или скрытая текстовая подпись у интерактивных элементов
- Предсказуемая и достаточная область взаимодействия
- Скрытый заголовок при отсутствии подходящего из макета

### Качество кода

- Валидная разметка (HTML-валидатор, БЭМ-валидатор)
- Код отформатирован
- Текст обработан типографом
- Отсутствие избыточного веса селекторов
- Все ссылки с href="#"
- Соблюдена логика файловой структуры
